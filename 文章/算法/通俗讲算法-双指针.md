hello,各位好啊，欢迎来到通俗聊算法系列，本系列致力于用通俗易懂的语言为大家讲解算法中常用的一些数据结构或者方法，今天来聊——**双指针**。

比较常见的双指针有两种——**头尾指针**和**快慢指针**。

先说头尾指针，依旧举例起手啊，有一群人排成一队，需要按排队顺序对这队人进行登记，正常讲要从第一个按顺序登记到最后一个对吧，这样做效率有点低，可以再加一个人，让他从队尾开始登记，这样两个人一起登记，速度就快了一倍。

双指针也是这样，定义一个变量 start，它的值为 0，代表数组开头的指针，对应从开头登记的那个人。定义一个变量 end，它的值为数组大小 -1，代表数组结尾的指针，对应从队尾开始登记的那个人。然后 start 每次循环 +1，end 每次循环 -1，这样遍历的速度可以快一倍。

当然，也可以是有条件的对指针进行变动，比如找到有序数组中相加等于特定值的两个数，如果 start + end > 目标值，则让 end 向左移动一格，反之则让 start 向右移动一格。

总而言之，头尾指针就是在一条线的两边有两个人，他们在进行双向奔赴。

然后是快慢指针，头尾指针是两个指针**一左一右、起点完全不同，互相朝着对方前进**；而快慢指针不一样，**两个指针一开始站在同一个起点位置**，全程朝着同一个方向前进，唯一的区别就是二者移动的速度不一样。

比较常用的速度设定是慢指针每次移动一格，快指针每次移动两格，就像两个运动员，一个一分钟能跑一圈，另一个一分钟能跑两圈。

快慢指针比较经典的一个用法是**判断链表中是否有环**，原理也很好理解：倘若链表里面存在环，那么先出发的快指针会先在环中绕圈，慢指针虽然慢一些，但最后也会进入环中在环中绕圈。两个指针一块在环里绕圈，那么两个指针迟早会在患者相遇，可如果链表从头到尾都是笔直无环的结构，那速度更快的快指针会直接率先走到链表末尾，永远都不可能和慢指针相遇。
