hello,各位好啊，欢迎来到通俗聊算法系列，本系列致力于用通俗易懂的语言为大家讲解算法中常用的一些数据结构或者方法，今天要聊的是——**滑动窗口**。

大家在坐火车、高铁、巴士的时候一定有过这样的经历，坐在座位上，随着车辆前进，窗外的景色不断变化——左边的旧风景慢慢滑出视线，右边的新风景不断涌进来。虽然窗口的大小没变，但一路上的所有景色，你都能通过这个小小的窗户看完整。

**滑动窗口算法**，干的就是这件事，滑动窗口有两种情况，分别是**固定窗口**和**可变窗口**。


首先是固定窗口，窗口的大小从一开始就定好了，然后你把这个“窗框”从左往右，一步一步滑过整个数组（或字符串）。每次滑动，只关心窗框里的那一段数据。

举个例子：找字母异位词

> 题目：给你两个字符串  
> s = `"cbaebabacd"`  
> p = `"abc"`  
> 要找出 s 中所有与 p 构成的字母异位词，并返回它们的起始下标。

先解释一下“字母异位词”：就是把一个单词（或短语）的字母重新排列，每个字母用一次，组成的新词。比如 `"abc"` 可以变成 `"cba"`、`"bac"` 等。

在这个例子里，s 中的 `"cba"`（下标 0~2）和 `"bac"`（下标 6~8）都是 `"abc"` 的异位词，所以答案应该是 `[0, 6]`。

接下来简单说一下使用固定窗口解决这题的思路

因为 p 的长度是 3，我们就用一个长度固定为 3 的窗口，在 s 上从左往右滑：

- 窗口 1：`"cba"` → 和 p 是异位词吗？是 → 记录下标 0
    
- 窗口 2：`"bae"` → 不是
    
- 窗口 3：`"aeb"` → 不是
    
- ……
    
- 窗口 7：`"bac"` → 是 → 记录下标 6
    

每滑一次，窗口里的内容整体换了一批，但我们不需要每次都从头比较，利用滑动窗口的特性可以快速更新。


然后是可变窗口，与固定窗口不同，可变窗口的大小是可以改变的，固定窗口像玻璃，只能拿着它在数组上滑动，可变窗口像橡皮泥，可以根据需求随意改变长度，通常用来解决“在满足某个条件下，找最长或最短的区间”。

经典题目：最长不重复子串

> 给定字符串 s = `"abcabcbb"`  
> 找出其中**不含重复字符的最长子串**，返回它的长度。

肉眼扫一下：`"abc"` 不重复，长度 3；再往后 `"abca"` 就有重复的 a 了；其实最长的应该是 `"abc"` 或 `"bca"` 或 `"cab"`，长度都是 3。最后答案是 3。

可变窗口怎么解决？

我们不用一开始就知道窗口多大，而是让窗口自己“伸缩”。

- 准备两个指针：为方便理解称它们为左窗框和右窗框，都从 0 开始。
    
- **不断移动右窗框** 向右扩大窗口，每加入一个新字符，检查窗口内是否有重复。
    
- **如果出现重复字符**（比如窗口里已经有 a，又来了一个 a），就移动左窗框向右缩小窗口，直到重复问题被解决。
    
- 每次窗口调整完毕后，窗口内的子串就是不重复的，记下它的长度。然后继续移动 right。
    

用 `"abcabcbb"` 走一遍：

1. 右窗框=0~2，窗口 `"abc"`，无重复，长度 3
    
2. 右窗框=3，字符 `'a'`，此时窗口里有 a 吗？有（下标 0），所以移动左窗框到原来的 a 后面（左窗框跳到 1），窗口变成 `"bca"`，长度 3
    
3. right=4，`'b'`，窗口里有 b（下标 1），左窗框跳到 2，窗口 `"cab"`，长度 3
    
4. right=5，`'c'`，窗口里有 c（下标 2），左窗框跳到 3，窗口 `"abc"`，长度 3
    
5. 继续往后，遇到 `'b'`、`'b'` 等，窗口长度只会变小或维持
    

最终最大长度就是 3。
