# 什么是链表

链表就像是手串一样，由一个个节点组成，和手串不同的是，链表有一个开头和结尾，当然也有和手串一样没有头尾而是一个环的链表，链表由以下几个部分组成：
- 节点：表示链表中的一个元素，就像手串上的一个珠子
- 数据：节点里储存的数据，就像手串上珠子的特征，比如大小、颜色等
- 指针：用于记住下一个节点的位置，就像连接珠子的线，它负责引导你找到下一个珠子，在单向链表中只有一个，顺着指针只能从头到尾遍历链表，不能从尾到头遍历，双向链表中有两个，分别记录上一个节点和下一个节点的位置，因此双向链表既可以正着遍历也可以倒着遍历。

# 链表的好处是什么？

相较于数组，链表显然麻烦了不止一点两点，那么它的优势在哪？增删极快，在数组中想要插入或删除一个数据需要修改那个位置之后的所有数据，而链表只需要修改两个指针就可以了，先将上一个指针指向要插入的节点，然后将插入的节点的指针指向下一个节点，完事。

当然，链表也不只有优点，它的缺点也很明显，查找极慢，数组想查找一个数据顺着索引走过去就像行，而链表需要一个节点一个节点的走过去，就像串门，数组就像路修在外面，顺着路到要去的地方进去就行，链表不一样，链表就像路是修在家里面的，必须先从第一户人家进去，然后顺着路进到第二户，第三户，这样慢慢走到要去的地方。

# 总结

1. 链表是“一串节点”，每个节点只记住下一个节点在哪里。
2. 链表的优点是增删快，缺点是查找慢
