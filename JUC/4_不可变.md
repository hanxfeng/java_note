
- 不可变类是线程安全的

- # 如何自己设置一个不可变类
  
	- ## final 的使用
	  
		- 对于一个不可变类，这个类本身，和类中的成员变量都是 final 的
		  
		- 使用 final 修饰成员变量，保证了该成员变量是只读的，不能修改。
		  
		- 使用 final 修饰类本身，保证了类中的方法不会被覆盖，防止子类破坏不可变性
	
	- ## 保护性拷贝
	  
		- 在传入的对象中有引用对象时，拷贝这个引用对象，将拷贝后的引用对象作为类中的成员变量，这样可以防止类外的其他变量也引用这个对象，在它更改时连带使类中的变量也进行更改
		  
		- String 中对于字符串的操作都会创建一个新字符串就是因为 String 进行保护性拷贝


- # 享元模式
  
	- 享元模式是为了在重用数量有限的同一类对象时，最小化内存的使用，具体做法是对相同取值的对象进行共享
