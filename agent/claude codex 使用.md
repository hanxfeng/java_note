- # CLAUDE.md
  
	- 在使用 agent 去写一个项目时，应该先写好 CLAUDE.md 文件（CLAUDE 一定全部大写），这个文件里存有项目概要，技术栈，代码风格与规范（例如变量与方法命名），项目架构与目录结构，一些规则（例如不要修改 mysql 服务器地址等），注意事项
	
	- 这个文件应该时时更新，如果 ai 在开发时出现错误，应该把犯过的错误写进去防止再犯
	
	- 出于上下文考虑，这个文件应当尽量精简
	  
	- 可以简述项目后让 ai 自行生成，然后自己进行调整


- # 常用命令
  
	- `/context` ：查看当前的上下文数据
	  
	- `/compact`：压缩当前上下文
	  
	- `/diff` ：查看修改的文件，可以使用方向键选择后使用回车键查看具体修改
	  
	- `/rewind` ：将修改回退到某次对话之前


- # 记忆
  
	- 记忆是指会长期保留的东西，claude 中记忆可以分为用户记忆和项目记忆两种
	  
		- 用户记忆：保存在 `C://用户//userName//.claude//CLAUDE.md` 中，无论在哪个项目中都生效
		  
		- 项目记忆：保存在项目的 `/CLAUDE.md` 中，只在当前项目中生效
